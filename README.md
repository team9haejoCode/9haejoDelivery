## 서비스 구성 및 실행 방법

##  기술 스택
- **언어:** Java 17
- **프레임워크:** Spring Boot 3.x
- **ORM:** Spring Data JPA(Hibernate)
- **DB:** PostgresSQL
- **인증/인가:** Spring Security + JWT
- **빌드:** Gradle
